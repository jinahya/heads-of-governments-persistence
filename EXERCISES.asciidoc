= Exercises
:toc: left
:toclevels: 3

The exercises on `db/heads_of_governments.sqlite3`: a section for each table, with a section for each level, and, at the end, a section for the schema as a whole.
Each exercise states the request it answers; the SQL that answers it is in the `.sql` file, under the same id.
The ids are registered in `EXERCISES.yaml`.

Parameters are bind variables (`:name`); the `sqlite3` shell binds one with `.parameter set :name 'value'`, and an IDE prompts for them when a statement runs.
An exercise with a parameter, or one that measures to `date('now')`, shows no output, since what it gives back depends on the value or the day.

Run a file as a whole:

[source,sh]
----
sqlite3 -readonly db/heads_of_governments.sqlite3 < src/test/sql/<file>.sql
----

== head

The `head` table: a row per term of a head of government.

=== Basic

[[HOG-HEAD-B-01]]
==== HOG-HEAD-B-01: Who held office on a day

A reader gives a date and wants each country's head on that day.
A country whose office was vacant is absent.

.`head_exercises_01_basic.sql`, HOG-HEAD-B-01
[%collapsible]
====
[source,sql]
----
SELECT country, number, name, party, term_start, term_end
FROM head
WHERE term_start <= :date
  AND (term_end IS NULL OR term_end >= :date)
ORDER BY country ASC
----

[[HOG-HEAD-B-04]]
==== HOG-HEAD-B-04: Terms by name

A reader types part of a name and wants every term of anyone matching it.
LIKE folds case for ASCII letters only, so 'churchill' finds Churchill and '吉田' finds 吉田茂; the index on name does not help a leading wildcard.

.`head_exercises_01_basic.sql`, HOG-HEAD-B-04
[%collapsible]
====
[source,sql]
----
SELECT country, number, name, term_start, term_end
FROM head
WHERE name LIKE '%' || :name || '%'
ORDER BY country ASC, term_start ASC
----

.`head_exercises_02_intermediate.sql`, HOG-HEAD-I-01
[%collapsible]
====
[source,sql]

SELECT number,
       name,
       term_start,

FROM head
WHERE country = :country
ORDER BY days DESC, term_start ASC

[[HOG-HEAD-I-07]]
==== HOG-HEAD-I-07: The latest terms of each country

Per country, the :n most recent terms, oldest of them first.
Terms, not persons: a head re-elected appears once per term. term_start is NOT NULL and distinct within a country, so the numbering has no ties.

.`head_exercises_02_intermediate.sql`, HOG-HEAD-I-07
[%collapsible]
====
[source,sql]
----
SELECT country, number, name, term_start, term_end
FROM (SELECT h.*, ROW_NUMBER() OVER (PARTITION BY country ORDER BY term_start DESC) AS latest_rn
      FROM head AS h)
WHERE latest_rn <= :n
ORDER BY country ASC, term_start ASC
----

====

[[HOG-HEAD-I-08]]
==== HOG-HEAD-I-08: The first and the latest terms of each country

Per country, its first :n terms and its most recent :n, each row saying which it is.
A row is 'first' when it is among the first :n, so with a country of 2 * :n terms or fewer the two sets overlap and 'first' wins.

.`head_exercises_02_intermediate.sql`, HOG-HEAD-I-08
[%collapsible]
====
[source,sql]
----
SELECT country,
       CASE WHEN first_rn <= :n THEN 'first' ELSE 'latest' END AS which,
       number,
       name,
       term_start,
       term_end
FROM (SELECT h.*,
             ROW_NUMBER() OVER (PARTITION BY country ORDER BY term_start ASC)  AS first_rn, ROW_NUMBER() OVER (PARTITION BY country ORDER BY term_start DESC) AS latest_rn
      FROM head AS h)
WHERE first_rn <= :n
   OR latest_rn <= :n
ORDER BY country ASC, term_start ASC
----

[[HOG-HEAD-I-11]]
==== HOG-HEAD-I-11: Party share of completed terms, the top three per country

Per country, over the terms that have ended, each party's share of the days in office as a percentage of that country's total (its tenure share), the top three parties; a succession ('A/B') counts as a party of its own.

.`head_exercises_02_intermediate.sql`, HOG-HEAD-I-11
[%collapsible]
====
[source,sql]
----
SELECT country, party, tenure_share
FROM (SELECT country,
             party,
             ROUND(100.0 * SUM(julianday(term_end) - julianday(term_start))
                       / SUM(SUM(julianday(term_end) - julianday(term_start))) OVER (PARTITION BY country),
                   1) AS  tenure_share,
             ROW_NUMBER() OVER (PARTITION BY country
                 ORDER BY SUM(julianday(term_end) - julianday(term_start)) DESC)             AS place
      FROM head
      WHERE term_end IS NOT NULL
      GROUP BY country, party)
WHERE place <= 3
ORDER BY country ASC, tenure_share DESC

                        term_end,
